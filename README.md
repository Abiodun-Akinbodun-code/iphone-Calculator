This calculator was built with a focus on simplicity and ease of use. It handles all the basic arithmetic operations you’d expect, and also includes a few helpful extras:
	•	✔ Square (x²)
	•	✔ Square Root (√x)
	•	✔ Percentage (%)
	•	✔ Delete (Backspace)
	•	✔ Clear Display (C)

The layout is clean and minimal, with a design that works smoothly on both desktop and mobile screens.
